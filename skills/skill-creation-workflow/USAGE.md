# skill-creation-workflow 使用说明

当你想创建、修改或审计一个 AI agent 技能时，使用 `skill-creation-workflow`。

## 适用场景

- 创建一个新技能。
- 把某个工作流沉淀为技能。
- 修改已有技能的行为。
- 审计某个技能是否符合仓库规范。
- 给技能补充 `USAGE.md` 或 `evals/evals.json`。
- 检查技能是否有中文输出约束。

## 使用方式

可以这样提出需求：

```text
帮我创建一个用于生成周报的技能，按 skill-creation-workflow 来。
```

```text
审计 skills/example-skill，看看它是否符合技能创建规范。
```

```text
把刚才这个流程沉淀成一个技能，要求所有产物用中文。
```

## 流程

1. 先用 `brainstorming` 确认技能目标、触发场景、输出格式和测试策略。
2. 等你确认后，再用 `skill-creator` 创建、修改或审计技能。
3. 技能源码写入 `skills/<技能名>/`。
4. 新建或修改的技能必须包含中文强约束，并优先写入 `<HARD-GATE>`。
5. 可测试的技能应补充 `evals/evals.json`。

## 中文约束

该流程要求新建或修改的技能默认使用中文，包括技能说明、交互说明、生成文档、测试记录、审计结论和产物说明。这个要求应作为硬门禁写入目标技能的 `<HARD-GATE>`；代码、路径、命令、API 名和技术术语可以保留英文。
