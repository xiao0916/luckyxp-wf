# dwf-development 使用说明

## 简介

`dwf-development` 是一个从 `dev-workflow` 中拆分出来的独立技能，专注于需求拆解、技术方案和实现清单三个阶段。

## 何时使用

当您需要：
- 单独执行 dev-workflow 的需求拆解、技术方案或实现清单阶段
- 生成技术方案文档
- 创建实现清单
- 从 dev-workflow 抽离这三个阶段

## 触发方式

使用包含以下关键词的请求：
- "需求拆解"
- "技术方案"
- "实现清单"
- "生成技术方案"
- "创建实现清单"

## 输入要求

- **必需**：需求文档（`01-需求文档/需求文档.md`）
- **可选**：设计稿（`02-设计稿/设计稿.md`）

## 输出文件

1. `03-需求拆解文档/需求拆解文档.md` - 功能拆解和范围边界
2. `04-技术方案/技术方案.md` - 至少 2 个技术方案对比
3. `05-实现清单/实现清单.md` - 有序的任务清单

## 运行模式

- **独立模式**：不依赖 dev-workflow 状态文件，只生成文档
- **工作流模式**：作为 dev-workflow 的一部分，更新状态文件

## 使用示例

```
用户：帮我生成技术方案
用户：需求拆解一下这个功能
用户：创建实现清单
```

## 注意事项

- 每个阶段都需要用户确认后才继续
- 技术方案至少提供 2 个对比方案
- 实现清单会尽可能拆分任务
- 所有生成文档默认使用中文
